# TalkVideo MCP

An independently maintained toolkit for agent-driven narration and local video production.

**Status: implementation in progress.** Production voice generation and real-person lip-sync are not enabled. Rights, provider availability, and local model compatibility must be verified before real media generation.

## Support

Questions, bugs, and feature requests for this project belong in [this repository's Issues](https://github.com/ktanino10/talkvideo-mcp/issues). Development and maintenance are the responsibility of this repository's maintainer.

This project is not an official TarakoTalk, CoeFont, or Hiroyuki project, and is not provided, reviewed, or endorsed by their authors or operators. Do not send support requests for this project to them.

## Intended scope

- A dedicated agent Skill and a Python stdio MCP server.
- Lossless long-text segmentation, audio jobs, inspection, revisions, and resumable processing.
- Local video processing with explicit review checkpoints.
- No automatic media uploads, upstream support requests, or cloud video processing.

Original project code will use the MIT license. Third-party code, voices, footage, and model weights retain their separate terms and are not automatically included or licensed for redistribution.
